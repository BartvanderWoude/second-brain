## Problem addressed

Incomplete and ambiguous bug reports delay triage and resolution because developers must recover missing context manually.

## Method

The study fine-tunes three open models to rewrite casual reports into a standard structure and compares them with ChatGPT-4o using CTQRS and text-similarity metrics.

## Result

Fine-tuned Qwen 2.5 scored 77% CTQRS, with Llama strongest on some missing-field detection and Qwen reaching 76% F1 for steps to reproduce.

## Synthesis

**Why relevant** — Better input quality can improve every downstream triage component without changing the assignment model itself.

**What would need to change to apply it** — Generated fields must be distinguished from reporter-provided facts and confirmed before entering a production issue tracker.

**Skeptical note** — Text-quality metrics do not establish factual correctness; a fluent rewrite can hallucinate reproduction details.
