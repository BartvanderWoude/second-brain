## Problem addressed

Learning-based program repair has many techniques, datasets, and evaluation practices but lacks a single operational overview.

## Method

The survey organizes the field around fault localization, patch generation, ranking, validation, correctness, datasets, metrics, and deployment concerns.

## Result

It provides a taxonomy and practical guidance, including explainable patch generation, richer code features, industrial deployment, and open-science considerations.

## Synthesis

**Why relevant** — It maps what can happen after triage identifies a likely fault and highlights evaluation pitfalls for automated repair.

**What would need to change to apply it** — The survey must be translated into concrete component choices and updated for newer agentic and LLM-based repair systems.

**Skeptical note** — A broad survey summarizes reported evidence but does not itself validate which methods generalize to a new repository.
