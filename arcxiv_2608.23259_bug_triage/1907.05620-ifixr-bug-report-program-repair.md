## Problem addressed

Automated repair usually assumes a revealing test suite, while many real bugs arrive only as reports. iFixR uses those reports to drive localization and patch generation.

## Method

Bug reports feed an information-retrieval fault localizer. Fix patterns generate patches, regression tests validate them, and candidates are ranked for developers.

## Result

On a reorganized Defects4J set, iFixR generated plausible or genuine patches for 21/44 faults and ranked one in the top five for 8/13 evaluated cases.

## Synthesis

**Why relevant** — It connects unstructured bug reports directly to localization and repair, extending triage toward executable maintenance actions.

**What would need to change to apply it** — A modern pipeline would need support beyond Java/Defects4J and robust handling of incomplete issue descriptions and repositories without mature tests.

**Skeptical note** — Plausible patches are not necessarily correct, and the reported subset is small.
