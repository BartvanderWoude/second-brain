## Problem addressed

Writing reproduction scripts manually is costly, while earlier automation often targets only narrow bug types such as crashes.

## Method

AEGIS extracts structured issue information, identifies relevant code, builds concise context, and controls script generation through a finite-state machine with multiple feedback signals.

## Result

The paper reports a 23.0% improvement in F-to-P over the state-of-the-art baseline and a 12.5% relative improvement in Agentless resolved rate.

## Synthesis

**Why relevant** — Reproduction converts a textual issue into executable evidence that can improve localization and repair downstream.

**What would need to change to apply it** — Integration requires repository execution sandboxes, language-specific test commands, and strict limits on agent actions.

**Skeptical note** — Benchmark reproduction success may not cover environment-dependent or nondeterministic production failures.
