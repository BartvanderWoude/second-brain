## Problem addressed

Incorrect file selection is a bottleneck that propagates errors into downstream localization and automated repair.

## Method

BLAgent encodes repository structure with path-augmented AST chunks, transforms bug queries from structural and behavioral perspectives, then reranks a bounded candidate set using symbolic and evidence-grounded reasoning.

## Result

It reports over 78% Top-1 accuracy with open models and over 86% with a closed model on SWE-bench-Lite, plus repair-success gains of up to 25%.

## Synthesis

**Why relevant** — It provides a bounded, cost-aware bridge from issue triage to repository localization.

**What would need to change to apply it** — Repository parsers, indexing, candidate limits, and cost budgets must be adapted to the target languages and codebase scale.

**Skeptical note** — SWE-bench-Lite may not represent proprietary repositories, sparse reports, or non-Python build environments.
